# 每日字踪发布说明

每日字踪按浏览器当地日期的日号选题：1 日使用第 1 题，31 日使用第 31 题，每月循环。较短的月份不会使用不存在的日号。进度按完整日期单独保存在本机。

## 维护循环题库

`index.json` 的 `puzzles` 数组使用 `day`（1–31）、`title` 和 `file` 登记题目，每个日号恰好一题。现有日期文件名保留，文件名不影响选题；JSON 内原有的 `date` 和 `number` 会在显示时替换为所选日期和循环题号。`startDate` 是可回玩的最早日期。

修改相应 JSON 的标题、提示、棋盘尺寸和 `words`，并同步清单标题。通过本地服务器打开 `http://localhost:端口/daily-strands.html?preview=2026-10-31` 可预览对应日号的题目。

`preview` 参数仅在本地主机生效，可预览未来日期且不保存进度。线上 `?date=2026-10-31` 仍不能提前打开未来日期。往期列表和周历使用同一循环规则。

每个 `path` 坐标都是 `[行, 列]`，从 `0` 开始。路径中的坐标数量必须等于词语的字数；相邻坐标可以横、竖或斜着连接。所有词的路径合起来应恰好覆盖棋盘的每个格子一次。

通关词是可选的。每道题可以没有通关词，也可以把一个词设置为 `"spangram": true`，但不能设置多个。使用通关词时，它的 `path` 必须接触上、下两边，或左、右两边。页面会在载入时检查这些规则；玩家提交答案时也会按 JSON 中的准确路径判断，正向和反向连接都可以。

`index.json` 是静态网站的谜题清单。浏览器不能自行列出服务器文件夹，所以新增 JSON 后也必须在这份清单登记。

## 经典字踪

`classic.json` 保存 `strands.html` 的全部经典关卡，包括“月”“春”和“学”。可以直接编辑该文件来修改或增加经典关卡；经典关卡不需要登记到每日谜题的 `index.json`。

由于 `strands.html` 会用 JavaScript 读取 `classic.json`，请通过本地预览服务器打开页面，不要使用 `file://` 地址直接打开。
