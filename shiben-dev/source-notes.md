# ChinaTextbook 来源与使用边界

本网站以 [TapXWorld/ChinaTextbook](https://github.com/TapXWorld/ChinaTextbook) 为资源导览来源。该仓库的公开说明表示，其整理初中、小学、高中、大学及不同学制的教材资源，并明确提及帮助海外华人让孩子了解国内教育的动机。

网站仅提供分类、说明与到原始公开目录的跳转，不复制、上传或二次托管仓库中的教材 PDF。教材文件、其著作权与任何第三方权利仍归相应权利人所有；使用者应根据所在地区的法律、教材版权说明以及原始页面信息自行判断可用范围。

仓库主页面未显示单独的开源许可证文件。网站底部将保留项目来源链接、原始仓库链接、非官方说明和权利提示，以避免暗示获得授权、官方背书或对教材拥有所有权。

## 浏览器功能核验（2026-08-22）

仓库的“小学”目录包含体育与健康、数学、科学、美术、艺术、英语、语文（统编版）、语文·书法练习指导、道德与法治（统编版）和音乐等学科目录。GitHub 的公开 Contents API 可返回目录、文件名、类型、网页地址及文件的原始下载地址；目录项目的 `download_url` 为空，需继续请求子目录。网站将以此 API 建立站内的逐层目录浏览，真实 PDF 文件则使用返回的原始地址在站内阅读器中打开；没有单一 PDF 地址的分卷文件会明确标识为“需下载后合并”。

在“小学 / 数学 / 人教版”的实测目录中，API 返回“义务教育教科书 · 数学一年级上册.pdf”等一至六年级上下册的单一 PDF 文件，并附带 `raw.githubusercontent.com` 的 `download_url`。因此阅读器可以默认从该真实目录开始，不采用虚构的教材清单，并允许用户继续向上或向下逐层浏览整个仓库。

站内测试已确认：默认目录载入了 12 个真实 PDF 项目（包括文件大小），用户点选不同册次后，阅读窗标题和原始 PDF 地址会同步更新。阅读器保留“在新标签打开”和“原始仓库文件页”两个兜底入口，以应对个别浏览器的内嵌 PDF 策略或网络限制。

进一步的导航测试确认：从默认教材册次可返回仓库根目录，并从根目录进入小学目录；小学目录会显示道德与法治、科学、美术、数学、体育与健康、艺术、音乐、英语、语文等真实学科文件夹。目录、文件夹和教材册次均可以在同一页面内继续切换，无需回到 GitHub 界面查找。

兼容性测试显示，仓库的 `raw.githubusercontent.com` PDF 地址会触发浏览器下载，而不是可靠地直接内嵌显示。为支持真正的站内翻页阅读，需要使用公开文档阅读服务加载该公开 PDF 地址，并同时保留原始下载链接作为不依赖第三方服务的备选入口。

外部文档阅读服务无法预览实测的 43.5 MB 教材文件，原因是文件过大。前端则能成功以 HTTP `200` 获取该公开原始 PDF 的元数据（约 45.6 MB，`application/octet-stream`）；因此网站已改用本地浏览器 PDF 渲染组件来加载源文件、显示页码并提供上一页/下一页与缩放控制，而不是依赖文件内嵌或第三方预览服务。

本地渲染器的真实浏览测试已成功呈现“义务教育教科书·数学二年级上册”的封面页，阅读控件显示全书共 115 页，并已加载上一页、下一页、缩小、恢复大小、放大与下载入口。浏览器控制台仅出现字体映射提示，不影响页面图像渲染；接下来仅需继续核验翻页交互。

最终交互核验已通过：触发“下一页”后，阅读器的画布标记和页码都从第 1 页切换为第 2 页（共 115 页）。移动端也能按顺序显示资料夹导航、文件列表、教材封面与翻页控件。

专注阅读交互测试已确认：点击“目录”控制后，左侧目录导航会在同页收起，文件列表与 PDF 阅读区随即横向扩展；控制按钮状态变为“展开目录导航”，使用户可随时恢复完整目录。

进一步测试已确认：用户可继续收起文件列表，使 PDF 阅读区成为主体；点击“专注阅读”后，阅读区会进入覆盖式最大化布局，并只保留教材标题、退出阅读、原始链接、缩放、下载与分页控件。该模式已经在真实 115 页教材上正常显示，并提供明确的退出入口。

分卷目录核验显示，仓库确实包含 `.pdf.1`、`.pdf.2` 等二进制分卷，例如“初中 / 体育与健康 / 华中师大版 / 七年级”下的“义务教育教科书·体育与健康七年级全一册.pdf_merge_folder”。合并器沿用用户提供方案的核心逻辑：按 `.pdf.序号` 分组和自然排序，再在浏览器内按字节顺序拼接为原 PDF 名称；没有文件上传环节。

站内目录已实测进入“初中”并返回 18 个真实学科目录，含“体育与健康”。分卷测试将沿该目录继续定位到 `_merge_folder` 中的 `.pdf.1`、`.pdf.2` 文件；合并工具本身仅在用户选中此类分卷时展开，以避免干扰普通 PDF 的阅读流程。

已通过站内真实交互进入“初中 / 体育与健康 / 华中师大版-华中师范大学出版社”，该目录包含七年级、八年级和九年级入口。其中七年级下的教材目录含经仓库核验的 `.pdf_merge_folder` 分卷路径，可用于验证本地合并工具的触发状态。

真实浏览验证已进入“义务教育教科书·体育与健康七年级全一册.pdf_merge_folder”，列表中显示同一教材的 `.pdf.1` 和 `.pdf.2` 两个分卷文件。选择其中任一文件后，阅读区会提供“合并并下载”与“清除选择”控制，确认本地合并器已同真实仓库的分卷命名规则接通。

合并器交互通过临时本地文件验证：选入顺序被打乱的“测试教材.pdf.2”和“测试教材.pdf.1”后，界面正确识别为同一份输出 PDF，显示两个分卷并启用“合并并下载”。测试文件仅在浏览器内存中使用，不涉及用户教材、上传或远程存储。

PDF 快捷键验证已在真实教材上通过：默认阅读器的“专注阅读”按钮显示 `F` 提示，按下右方向键后页码和画布从第 1 页切换到第 2 页（共 115 页）。阅读器同时提供快捷键面板，列出方向键/PageUp/PageDown 翻页、加减号缩放、`0` 重置、`F` 专注阅读、`Esc` 退出和 `H` 显示/隐藏提示。

专注模式快捷键已进一步验证：按下 `F` 后阅读器切换为“专注阅读 / 只保留教材”并显示退出提示；按下 `Esc` 后退出覆盖式阅读并恢复常规页面，同时保留教材当前第 2 页，未丢失阅读进度。

缩放快捷键也已量化验证：在真实教材第 2 页中，按 `0` 后画布宽度为 678 像素；按 `+` 后画布宽度增至 756 像素；再次按 `0` 后恢复为 678 像素。因此放大和重置均会重新渲染当前教材页面。

控制项条件显示已验证：在正常 PDF 状态，阅读区显示“专注阅读 F”与 PDF 相关快捷键；返回仓库根目录后，当前选中 README.md（不可预览）时，阅读区仅显示目录/文件切换与原始文件入口，不再出现“专注阅读”、PDF 缩放、翻页或快捷键控制。该规则同样适用于无文件引导和分卷文件状态。

合并后站内打开入口已在真实仓库的分卷目录中验证：沿“初中 / 体育与健康 / 华中师大版-华中师范大学出版社 / 七年级 / 义务教育教科书·体育与健康七年级全一册.pdf_merge_folder”进入后，阅读区显示本地文件输入框和“合并并在本站打开”按钮。

本地合并初测表明，浏览器运行环境会拦截阅读器把 `blob:` 地址当作远程地址读取。实现随即调整为：合并器将完整 PDF 的 `Uint8Array` 直接交给 PDF 渲染器，同时保留独立的本地 Blob 下载链接。因此分页渲染不再经过地址代理，下载仍可在浏览器本地完成。

修复后的站内阅读已通过验证：在真实分卷目录中，使用两个顺序打乱的临时有效 PDF 分卷完成合并后，阅读器显示“本地合并完成 / 站内阅读”，标题为“本地阅读测试.pdf”，并成功渲染“第 1 页”画布，无渲染错误。整个测试仅使用浏览器内存中的临时文件。

自动合成功能已在真实仓库分卷教材上验证：进入“义务教育教科书·体育与健康七年级全一册.pdf_merge_folder”后，系统自动下载同名的 `.pdf.1` 和 `.pdf.2` 分卷、按序拼接，并在无需手动选择文件的情况下打开站内阅读器。验证时阅读器显示完整教材标题及第 1 页画布，未出现自动下载错误。
