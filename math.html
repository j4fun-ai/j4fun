玩法说明

题目与标准答案来自小米开源的 CMATH 中文小学数学数据集。选择年级时页面会从 GitHub 获取该年级的最新题目；网络不可用时使用站内附带的本地缓存。选择项生成、判题和战绩记录均在浏览器本地完成，不上传答题内容。本页面由 j4fun 独立制作，与 CMATH 作者或维护者没有隶属、合作或认可关系。

今日一题怎么玩

每天的题目按日期固定，答对可以累计连胜天数，答错也没关系，明天会换新题。

数学闯关怎么玩

从一年级开始，每关 5 题，答对 4 题以上才能进入下一年级，全部通过就是「小学数学满分水平」。

数据范围

本地缓存包含 CMATH 开放的 600 道题，一到六年级各 100 道。可在 GitHub 查看原始题库。
